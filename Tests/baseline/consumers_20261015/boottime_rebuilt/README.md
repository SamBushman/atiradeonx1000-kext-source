# Rebuilt kext as the REAL boot-time driver (2026-10-15 17:34 onward, #45 final phase)

**How the boot driver was actually replaced (and the earlier mistake):** the boot-time accelerator comes from the prelinked kernel cache `/System/Library/Caches/com.apple.kernelcaches/kernelcache.86C01707`; copying the binary into `/System/Library/Extensions/ATIRadeonX1000.kext` alone changes nothing (the 09:18 "boot-time rebuilt" DVD IDCT run was stock vs stock and is retracted: `../../perf/dvd_idct_20261015_boottime_rebuilt_vs_stock/README.md`). After `sudo touch /System/Library/Extensions` the cache is stale, the system boots without it and kextd loads the accelerator from Extensions. Verified from the loaded image's size, not from the on-disk md5: `kextstat` = `78 0x71bac000 0x53000 0x52000 com.apple.ATIRadeonX1000 (4.1.9)` (rebuilt binary md5 2de86c49..., size 0x53000/0x52000; the stock kext shows 0x4f000/0x4e000 at 0x588000). Note: this boot driver is loaded by kextd rather than prelinked; the stock baselines below were measured with the prelinked stock driver on a fresh boot (a stock control loaded the same way can be added if a difference needs it).

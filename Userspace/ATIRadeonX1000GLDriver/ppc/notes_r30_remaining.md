## Caveats - RESOLVED in r33 (commit 65b64b9c)
All three caveats below were open when this round wrote them; r33 ran them down to ground truth and fixed/renamed accordingly. Kept here for history; see names_r30_misc.tsv/names_q08_22.tsv/names_q08_19.tsv/names_q08_26.tsv for the current rows.
- `MachineAssembler__visitIfHeaderStatic`'s `headerNode` → **`headerBlock`, CONFIRMED**. The vtable slot this call dispatches through (MachineAssembler virtual slot 13, byte offset 0x34) was ground-truthed against the real stock binary (ATIRadeonX1000GLDriver.bundle.bin, `Tools/userspace/data_sections.py`): the R300MachineAssembler vtable at that slot points to `R300MachineAssembler__assembleBlock(this, block, startOfShaderFlag)`, whose own declared 2nd parameter is literally named `block`. So the value really is a block being assembled, not a generic/ambiguous node.
- `MachineCodeWriter__encodeProgram`'s `codeSink` → **`sinkObject`, CONFIRMED**. Same `EncoderState+0x20` field that `EncoderState__destroy_e3244`/`EncoderState__destroy_e3308` (same file) already name `sinkObject` when releasing it through their own vtable slot 4 call; unified onto one name for one field.
- The `staleArgN` numbering inconsistency is fixed. Ground truth (via `git show <introducing commit>` for each): the correct, majority convention (part_053.c/part_054.c, matching Ghidra's own original `in_rN` names) is that N is the literal PPC register the stale value sits in. 6 functions across part_047/048/008 (the `ValueKey__fold*IntoOutputScale`/`foldMulOfConstants`/`replaceWithLaneConstants` family, `extvsMakeShaderCurrent`) had instead been numbered by position among the call's visible arguments - renumbered to the true register (staleArg6/7/8 etc). Also fixed a related miscategorization found during this pass: `ValueKey__evalLitLane`'s dead 4th parameter was mislabeled `staleArg4` (a register-forwarding name) when it's actually a dead FORMAL PARAMETER, which belongs in the project's `unusedArgN` category instead (cf. `pairIndex`'s `param_1`→`unusedArg1`) - renamed to `unusedArg4`.

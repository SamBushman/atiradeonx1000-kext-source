Directed controls and static detectors used for #297-#299 (Nov 16). Paths inside point at the session's scratch layout (`~/g5logs/fnf_237/<img>/`): adapt `G`/`img` before use.
* `ctl_quant.py IMG` - gld_quantizePointSizeInt with f1 = +-2^23..2^25 edge values (stock vs rebuilt r3); the old image differs, a fixed image is identical.
* `ctl_v85.py IMG NAME...` - the vslot85_findOrEncodeConstantVector family with four equal float words; hooks the callee Program__findOrCreateConstInst and prints the 16-byte vector it receives.
* `fpprec.py` / `magprec.py` / `fpseq.py STOCK REBUILT LEDGER NM [names]` - single/double FP op counts and int-to-float magic-constant counts per function (capstone skipdata; over-reports: only "stock 0, rebuilt >0" is a reliable signal).
* `lastpc.py PKL NAME` - replay one saved trial and print the last instructions each image executed before its fault.
* `ctl_entryargs.py IMG NAME...` - TD_ENTRYARGS control: the vslot85 rows with four equal float words; prints the callee argument records of Program__findOrCreateConstInst and the compare verdict. Old image (v15): EFFECTS 'callee argument record differs' (stock 0x3f800000 words, rebuilt the int-to-float converted words); fixed image (v20): IDENTICAL. TD_ENTRYARGS=1 makes `trace_diff.py` record, at every call of an in-image ledger function (library stubs excluded), the words the caller wrote into its own frame at each pointer argument r3..r10 (up to 16 contiguous written words, frame bytes written before the caller's stwu are ignored) and compare them per callee between the images; a callee present in only one image or called a different number of times is skipped, printf-family callees are skipped (their pointer is the varargs register save area with stale r9/r10).
* `wr_pc.py PKL NAME ADDR [N]` - replay a saved trial and print the last N instructions each image executed before the first write to ADDR (finds the store site of an EFFECTS row). `pf_pc.py PKL NAME` - print the pointer-argument records at each in-image call (TD_ENTRYARGS debugging).
